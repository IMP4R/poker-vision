# Poker Vision

Исследовательские OCR-наблюдение покерного стола и solver; без гарантий стратегии.

## Состав

- `PUBLICATION.md`
- `jev-poker`/
- `poker-nn`/

## Подготовка и запуск

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.

## Ограничения снимка

- OCR/визуальное наблюдение и solver в одном семействе. Веса, скриншоты, журналы раздач и браузерные данные не включены. Прибыльность и оптимальность стратегии не заявляются.
- При оформлении репозитория приложение не развёртывалось, платежи и внешние API не запускались; тесты не перепроверялись.
